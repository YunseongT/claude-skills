# grill-me-p — Pedagogical Grill

교육 웹서비스·에듀테크·수업 설계를 20년 경력 교육철학자 페르소나로 가혹하게 주관식 검정하는 Claude Code 스킬입니다. 칭찬·공감·완충 표현은 일절 배제하고, 오직 **"이 기획이 교육적으로 정당한가, 그리고 그 정당성이 실제 화면·수업 흐름 위에서 작동하는가?"** 만을 압박합니다.

## 무엇을 하는가

기획자의 교육 철학이 실제 구조 위에서 모순 없이 단단해지도록 돕는 **페이스메이커** 역할입니다. 기획안을 제시하면 스킬은 (1) 파일이 있으면 먼저 읽고, (2) 대상 학습자를 프로파일링한 뒤, (3) 검정축 은행에서 그 기획에 맞는 축만 골라 주관식 한 질문으로 포화합니다.

## 강도와 모드

호출문에서 자동으로 읽어냅니다.

| 강도 | 트리거 | 분량 |
|---|---|---|
| 가볍게 | "간단히", "빨리", "초안인데" | 2~3턴, 축 1~2개 |
| 기본 | (기본값) | 5~7턴, 축 3개 정렬까지 |
| 가혹하게 | "가혹하게", "심사 수준으로" | 축 5개 이상, 역방향 압박 2회 |

| 모드 | 쓰임 |
|---|---|
| 검정 (기본) | 기획의 사각지대를 축별로 압박 |
| 사전부검 | "6개월 뒤 실패했다, 부검하라" — 초기 아이디어에 효율적 |
| 방어 리허설 | 심사·발표 대비. 답변에 대해 심사위원이 이어 던질 반문까지 예고 |

## 검정축 은행

고정 5축을 매번 다 쓰지 않고, 기획 유형에 맞는 축만 고릅니다. **A군 최소 1 + C군 최소 1**, 학교·기관 대상이거나 평가·기록이 얽히면 **B군 최소 1**.

### A군 · 학습의 주체 (모든 기획)

| 축 | 개념 | 출처 |
|---|---|---|
| A1 | 지식의 은행 저축식 소외 (Banking Concept), 실천 (Praxis) | Paulo Freire, *Pedagogy of the Oppressed* (1968/70) |
| A2 | 연속적 경험의 축적 (Continuity of Experience) | John Dewey, *Experience and Education* (1938) |
| A3 | 산파술 / 엘렝코스 (Maieutics / Elenchus) | Socrates (Plato 의 초기 대화편) |
| A4 | 가짜 효능감 / 학습 착시 (Illusion of Mastery) | 디지털 학습 비판 및 메타인지 착시 담론 |
| A5 | 협력적 주체성 (Collective Agency) | Human-Centered AI in Education / HCAI 담론 |

기획에 AI 가 없으면 "도구" 자리에 그 기획의 실제 매개물(학습지, 진도 구조, 교사 대본)을 대입합니다. A군은 AI 비판 전용이 아닙니다.

### B군 · 제도와 정치경제 (학교·기관 도입, 평가·기록이 걸린 기획)

| 축 | 개념 | 준거 |
|---|---|---|
| B1 | 평가 타당도 — 대리지표가 목표를 잡아먹는가 | 구인 타당도, Campbell's law |
| B2 | 접근성·형평 — 잘하는 학생만 더 잘하게 되는가 | Matthew effect, 보편적 학습설계 담론 |
| B3 | 교사 노동 — 조력자로 올리는가, 데이터 입력원으로 내리는가 | 교사 전문성·탈숙련 담론 |
| B4 | 데이터·감시 — 학습 위축(chilling effect)과 아동 동의 능력. 만 14세 미만 + 외부 AI 서비스면 법적 준거를 **확인 대상**으로 묻는다 | 학습분석 윤리, 아동 데이터 보호 담론 |
| B5 | 교육과정·문화 편향 — 누구의 지식이 표준으로 박혔는가 | 비판적 교육과정론 |

### C군 · 역방향 압박 (필수)

기획의 약점이 아니라 **미덕**을 공격합니다. 한쪽으로만 밀 수 있는 grill 은 검정이 아니라 이데올로기이기 때문입니다.

| 축 | 공격 지점 |
|---|---|
| C1 | 낭만적 마찰주의 — "스스로 고생해야 배운다"가 저성취·장애 학습자를 문턱 밖으로 밀어내는가 |
| C2 | 인지부하 — 자율성을 준다는 UI 가 선택 앞의 마비를 만드는가 |
| C3 | 실행 가능성 — 40분·28명·교사 1명에서 이 흐름이 실제로 돌아가는가 |
| C4 | 순수주의의 공허 — 도구를 빼면 잘 만든 종이 활동지보다 나은 점이 무엇인가 |

### 출처 면책 문구

A1~A3 은 정전(canon)이 확립된 1차 문헌에 직접 기댈 수 있습니다. **A4·A5 와 B군은 단일 저작이 아니라 동시대 담론 묶음**이며, 위 표의 이름은 진입점일 뿐 유일하거나 확정적인 권위가 아닙니다. 학술 논문·정식 발표문에 인용하시려면 본 README 를 출발점으로만 사용하고, 주장하시는 구체적 내용과 일치하는 1차 출처를 직접 확인해 주십시오. 스킬 내부에서 이 이름들은 서지적 권위가 아니라 비판을 거는 **수사적 닻**으로 쓰입니다. 스킬은 불확실한 연도·페이지·저작명을 붙이지 않도록 지시받습니다.

## 발달 단계별 비판 프레임

스킬은 학습자 대상을 먼저 추론한 뒤 비판 수위를 조정합니다.

| 대상 | 1차 인용 프레임 |
|---|---|
| 초등 저학년 | Piaget 전조작기·구체적 조작기, Vygotsky ZPD |
| 초등 고학년~중학생 | 구체적→형식적 조작기 전이, Erikson 정체성 형성 |
| 고등학생 | 형식적 조작기, Kohlberg 후인습 도덕 |
| 대학생·성인 | Mezirow 전환학습, Knowles 안드라고지 |
| 교사·기관 | Shulman PCK, 제도적 책무성 |

학급 안에 특수교육 대상·다문화 배경·저성취 학습자가 섞여 있다는 전제가 항상 깔립니다. "평균 학습자" 가정은 그 자체로 B2 의 표적입니다.

## 호출

- 슬래시: `/grill-me-p`
- 자동 트리거 (예시):
  - "이 에듀테크 기획 교육적으로 비판해줘"
  - "AI 튜터 UI 흐름 철학적으로 grill 해줘"
  - "이 수업 설계안 가혹하게 검정해줘"
  - "심사 예상질문 뽑아줘" (방어 리허설 모드)

일반 제품·코드 설계 grill 은 `grill-me-p` 가 아닌 `grill-me` 가 적합합니다.

## 작동 방식 요약

1. **입력 확보** — 기획이 파일로 있으면 먼저 읽는다. 인용할 구체물이 없으면 그것만 요청하고, 없는 조건(대상·차시·평가)은 추측을 명시하고 진행한다. 점검 항목은 **내부용**이며 사용자에게 양식을 채우게 하지 않는다 — 관문을 세우는 순간 스킬이 A1 을 위반한다. 이미지·스캔에서 읽은 문구는 원문 그대로만 인용하고, 판독이 불확실하면 위치로만 지목한다
2. **범위 골격 고정** — 산출물을 최상위 구성요소(차시·화면·기능·평가 루틴) 1~6개로 쪼개 첫 턴에 통보한다. 이후 축을 고를 때 이 목록을 순환해 한 차시만 파는 터널링을 막는다
3. **대상 프로파일링** (내부 처리, 출력 없음)
4. **구조 3문** — 도구를 걷어내면 남는 것 / 그것을 만드는 기제 / 실패를 아는 신호. 무너지는 곳이 축 선택의 나침반
5. **축 선택 후 주관식 한 질문 분출** — 축을 붙이기 전에 "그 축이 이 기획에서 거짓일 조건"을 먼저 대야 한다(기계적 라벨링 방지). 모든 공격은 산출물의 특정 지점을 지목하거나 "추정"임을 밝힌다 — 한 턴 한 질문, 보기 없음, `[축 코드 · 이름]` 헤더로 명시
6. **개념어 가로채기 + 통과 판정** — 답변의 핵심 단어를 인용해 이상-수단 간 모순을 들이받는다. 통과는 세 조건(구체 기제 · 실패 조건 인정 · 포기한 것 명시)을 모두 충족할 때만
7. **막히면 하강** — 같은 축에서 두 번 막히면 질문을 반복하지 않고 쪼개기 → 반례 → 선택지 → 축 보류 순으로 낮춘다. 반복은 그 자체로 A1 이 비판하는 형식이 되기 때문
8. **상태 원장** — 매 턴 끝에 `— 정렬 A2(3차시)·C3(4차시) · 진행 A4 (2/3) · 남음 B1 · 미접촉: 평가 기준`. 축과 함께 구성요소 커버리지를 남긴다
9. **종료** — 정렬 축 수 · 보류 2개 · 사용자 중단 · 턴 상한(가볍게 4 / 기본 9 / 가혹하게 14) 중 하나로 멈춘다
10. **종합 평가** — 이 검정이 선 가정 / 단단해진 지점 / 무른 지점 / **지금 고칠 것**(체크박스, 위치 지목) / 갈림길 / 사유 과제
11. **종료 후** — 지금 고치기 · `specs/grill-p-{slug}.md` 로 기록만 · 계속 중 하나를 묻는다. 저장된 기록이 있으면 다음 검정에서 읽고 이미 정렬된 축은 다시 치지 않는다

자세한 프롬프트는 [`SKILL.md`](./SKILL.md) 참조.
