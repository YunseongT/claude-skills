# desoemat — 쇠맛 덮어쓰기 퇴고

Korean web-novel / fiction revision skill that removes the machine texture ("쇠맛") of AI-generated prose. Runs in Korean; see [README.ko.md](./README.ko.md).

Core idea: don't *delete* AI signals — that leaves a chain of short dramatic sentences, which is itself the current AI house style. Instead, re-say the same information in a target voice (project tone rules, the manuscript's own most human paragraphs, or a reference author) so the edited sentence can't be told apart from its neighbours.

- Triggers: "쇠맛 빼줘", "AI 티 없애줘", "문체 퇴고해줘", "번역투 고쳐줘", or any request to polish an AI-drafted chapter.
- Not for: writing new scenes from scratch, or non-fiction documents.
